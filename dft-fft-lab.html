01 · Understand the DFT

X[k] = Σn=0N−1 x[n] e−j2πkn/N,   k = 0, …, N−1

FFT is an algorithm for evaluating this same DFT. It is not a different transform. FFT and DFT use the same N-point input, sign convention, and scaling below.
